# KinChat

A personal messaging application designed to cleanly separate communication between family and office colleagues. 

## Overview
KinChat provides a streamlined interface to manage your conversations. It categorizes contacts into groups (like "Family" and "Office") so you can easily navigate between personal and professional discussions without them bleeding into each other.

## Features
- **Categorized Contact Lists**: Easily flip between Family and Office contacts.
- **Dedicated Chat Interfaces**: Clean, focused chat screens for ongoing conversations.
- **Responsive Design**: Works beautifully across mobile, tablet, and desktop views.

## User Flows
- **Home Screen**: View your main contact list, switch tabs to filter by Family or Office, and tap a contact to start messaging.
- **Chat Screen**: Send and receive messages in a familiar chat-bubble layout.

## Tech Stack
- Flutter
- Material 3 Design System

## Setup and Run
1. Ensure you have Flutter installed.
2. Clone the repository and run `flutter pub get`.
3. Run the app using `flutter run` on your preferred device or emulator.
